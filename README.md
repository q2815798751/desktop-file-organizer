# 桌面文件收纳 Desktop File Organizer

> Windows 桌面文件自动整理工具 —— 托盘 + 桌面悬浮面板 + 仪表盘，10 套精心设计的主题。

把散落在桌面上的文件自动归入分类，用悬浮面板和仪表盘统一管理；分类文件夹存放在桌面之外，桌面保持整洁、永不遮挡你的工作窗口。

---

## 特性

- **自动归类**：监控桌面，新文件按扩展名自动移入对应分类（Word/Excel/PDF、压缩包、文本、图片等）。
- **桌面悬浮面板**：每个分类一个面板，**置底不遮挡其他应用窗口**；面板可**磁吸对齐**（靠近自动贴边）并**编组整体拖动**。
- **拖拽收纳**：把资源管理器里的文件/文件夹直接拖到面板或仪表盘上，即移入该分类。
- **仪表盘**：分类管理、全库搜索、办公文件按 Word/Excel/PDF 子类型筛选、新建分类/文件夹、删除（进回收站）。
- **重复文件检测**：按内容（先比大小、再算 sha256）找出重复文件并分组列出，可批量删除多余副本（进回收站）。
- **独立面板开关**：仪表盘侧边栏每个分类都有「面板 ●/○」开关，可单独显示/隐藏该分类的悬浮面板；侧边栏可左右拖宽，超长分类名自动省略不遮挡。
- **苹果风界面**：悬浮式半透明自动隐藏滚动条、更大更清晰的字号（0.85–1.5 五档）、柔和无硬边框布局。
- **10 套主题**：仪表盘 + 悬浮面板 + 托盘全局换肤，另可调**面板透明度**与**字号**。
- **桌面整洁**：分类文件夹存放在桌面外的存储目录（默认 `文档\桌面文件收纳`），桌面只留快捷方式。
- **首次安装可选存储目录**：首次运行弹出「选择文件收纳的存储位置」，可浏览选择任意目录（如 `E:\beifen\桌面文件收纳`）；不做选择则默认使用系统文档目录。
- **桌面图标自动排列**：启动时把桌面图标对齐到网格；可在 `config.json` 里把 `arrange_icons` 设为 `false` 关闭（默认 `true`，保持现有行为）。

## 环境要求

- Windows 10 / 11（依赖 Win32 API，仅支持 Windows）
- Python 3.9+（开发环境为 3.14）
- 依赖：`PyQt5`、`watchdog`（必需）；`pywin32`（**可选**，见下）
  - `pywin32` 只用于把「开机自启」创建成启动文件夹里的 `.lnk` 快捷方式。**未安装时 `config.py`
    会自动降级**：改为在启动文件夹写一个 `.bat`，开机自启仍可用，只是登录时会闪现一个控制台
    窗口。核心的桌面整理功能不依赖它，所以没写进 `requirements.txt`（仅以注释标注为可选依赖）。

## 安装

```bash
pip install -r requirements.txt
```

## 运行测试

测试用 Python 标准库 `unittest`（**零新依赖**，不需要 pytest），覆盖 `file_manager.py`
的纯逻辑：桌面/存储路径解析、分类文件夹解析、文件名冲突消解、按扩展名归类、拖拽移入分类。

在仓库根目录执行：

```bash
python -m unittest discover -s tests -v
```

全部用例都在 `tempfile.TemporaryDirectory()` 里造临时目录，并把配置里的
`desktop_path` / `storage_path` 指向临时目录——**不会触碰真实桌面或真实用户文件**。
测试不导入任何 GUI 模块（`dashboard.py` / `desktop_panel.py`），可在无 PyQt5 的环境下运行。

## 打包与分发

用 PyInstaller 打包成**免安装的单个可执行文件**（单文件，双击即用）：

```bash
pip install pyinstaller
python -m PyInstaller --onefile --windowed --name DesktopFileOrganizer --icon app_icon.ico main.py
```

产物为单个 `dist/DesktopFileOrganizer.exe`（约 38 MB）。**注意**：`dist/`、`build/`、`*.spec`、
`*.lnk` 都被 `.gitignore` 忽略，构建产物与本机快捷方式**不随仓库分发**，需要自己生成：

- Inno Setup 安装程序 `DesktopFileOrganizer-安装程序.exe`（安装向导 + 开始菜单/桌面快捷方式 + 卸载项；安装到用户目录，免管理员）由本地编译产出到 `dist/`；便携安装包（含 exe 与使用说明，解压即用；不含本机 `config.json`）同样需本地打包。
- 项目根目录快捷方式 `桌面文件收纳.lnk` → 指向该 exe，双击即可打开（图标用 `app_icon.ico`）。该快捷方式属**本机自建**（`*.lnk` 被 `.gitignore` 忽略），不会出现在克隆下来的仓库里。

仓库实际跟踪的是打包**脚本**，不是二进制产物：Inno Setup 脚本 `installer/DesktopFileOrganizer.iss`
（编译：`ISCC.exe installer\DesktopFileOrganizer.iss`，需先构建出 `dist/DesktopFileOrganizer.exe`）
与 `installer/使用说明.txt`。

> 注：PyInstaller 单文件版偶被部分杀毒软件误报。打包时若需规避，可改用 `--onedir`（产物在 `dist/DesktopFileOrganizer/`）。

## 使用

```bash
python main.py
```

启动后：

1. **首次运行**弹出「选择文件收纳的存储位置」：选任意目录，或直接确定使用默认（系统文档 `文档\桌面文件收纳`）。随后在存储目录创建分类文件夹。
2. 桌面上出现各分类的**悬浮面板**，系统托盘出现图标。
3. **双击托盘图标**打开仪表盘；托盘右键可显示/隐藏面板、新建分类、开关开机自启、退出。

常用操作：

| 操作 | 方式 |
|---|---|
| 打开文件 | 面板或仪表盘中双击文件 |
| 收纳文件/文件夹 | 从资源管理器**拖拽**到面板或仪表盘 |
| 整理面板 | 拖动面板靠近另一块 → 磁吸对齐；边缘相接后面板**编组拖动** |
| 换主题 / 调透明度 / 字号 | 仪表盘右上角 **设置** |
| 新建文件夹 | 仪表盘「新建文件夹」（在当前分类内创建子文件夹） |
| 查找重复文件 | 仪表盘右上角「重复文件」（见下） |

### 重复文件检测（AW-22）

仪表盘右上角的 **「重复文件」** 按钮会扫描所有分类目录，找出**内容完全相同**的文件
（不同文件名、不同分类也算），按「组 → 文件（名称 / 大小 / 所在分类）」列出，
可勾选多余副本一键删除——**删除走回收站，可随时还原**，不会永久删除。

- 判定方式：先按**文件大小**分组，只有同尺寸的候选才计算 **sha256**（不整盘哈希，
  文件多时也很快），再按哈希分组；同组 2 个以上即为重复。
- 扫描范围：各分类目录下的**全部文件，含子文件夹（递归）**，**只读**——扫描本身
  不移动、不删除任何文件。
- **不越界**：递归时对每个条目做 `realpath` 复检，若某个子目录是指向存储目录之外的
  **junction / 符号链接**，整棵子树会被跳过（记 WARNING），不会把别的目录扫进来。
- **空文件（0 字节）不算重复**（没有内容可清，报出来只是噪音）；
  大小相同但内容不同的文件**不会**被误报。

## 分类与存储

默认分类（可在仪表盘新建/编辑/删除）：

| 分类 | 扩展名 |
|---|---|
| 办公文件 | doc, docx, xls, xlsx, csv, pdf（内部按 Word/Excel/PDF 筛选） |
| 压缩包 | zip, rar, 7z |
| 文本文件 | txt, md, log |
| 图片 | jpg, jpeg, png, gif, bmp, svg |
| 其他 | 手动整理（存放项目文件夹等，不自动归类） |

分类文件夹存放在 **存储目录**（默认 `C:\Users\<用户名>\Documents\桌面文件收纳`），可通过 `config.json` 的 `storage_path` 自定义，或**首次安装时在选择对话框中直接指定**。桌面本身只保留快捷方式。

> **安全行为（AW-19）**：分类的 `folder`（子文件夹名）不能为空、不能是绝对路径、不能含 `..`，
> 也不能解析到存储目录之外。若 `config.json` 里存在这样的非法值（手工编辑，或旧版本遗留），
> 程序**不会崩溃**：该分类会被**跳过**并记一条 ERROR 日志，其余分类照常工作。
> 此外，若某个分类目录被替换成指向存储目录之外的 **junction / 符号链接**，
> 同样会被拒绝并跳过（避免文件被悄悄写到存储根之外）。需要把分类放到别的盘时，
> 请改 `storage_path`，不要链接单个分类目录。

> **拖拽保护（AW-4）**：把**存储目录本身或其上级目录**（如 `Documents`）拖进分类会被
> **静默拒绝**。这是**纵深防御 + UX 改善**，并非在堵一个可达的数据丢失缺陷——即使没有
> 这层校验，搬移也会因「目标目录在源之内」被系统以 `WinError 5` 拒绝，存储目录不会位移；
> 加校验只是把这种情况变成**干净的拒绝**（而不是「尝试搬移 → 失败 → 记一条 ERROR 日志」）。

## 配置

`config.json` 由程序在首次运行时自动生成（本仓库不提交本机配置），字段：

| 字段 | 说明 |
|---|---|
| `categories` | 分类列表（name / extensions / folder / subtypes） |
| `panels` | 悬浮面板位置与折叠状态 |
| `desktop_path` | 桌面路径 |
| `storage_path` | 分类存储根目录 |
| `theme` | 当前主题（见 `themes.py`） |
| `panel_opacity` | 面板透明度 0.5–1.0 |
| `font_scale` | 字号比例 0.85 / 1.0 / 1.15 / 1.3 / 1.5 |
| `auto_start` | 是否开机自启 |
| `arrange_icons` | 启动时是否自动重排桌面图标（默认 `true`；设为 `false` 关闭） |
| `initialized` | 是否已完成首次文件归类 |

## 项目结构

```
main.py          入口：托盘、面板、仪表盘协调
dashboard.py     仪表盘主窗口（搜索 / 分类 / 文件管理 / 设置）
desktop_panel.py 桌面悬浮面板（置底、磁吸、编组拖动、拖拽收纳）
file_manager.py  文件归类 / 移动 / 存储路径解析
file_watcher.py  watchdog 桌面监控（自动归类新文件）
panel_manager.py 面板生命周期与状态持久化
themes.py        10 套主题定义
icons.py         QPainter 矢量图标库
config.py        配置读写与默认值
restore_files.py 工具：把分类文件夹中的文件移回桌面
```

## 说明

- 删除文件进入**回收站**，不会永久删除。
- 若想恢复文件到桌面，运行 `python restore_files.py`。
- 本机 `config.json` 不入库（含个人路径）；参考 `config.example.json`。
